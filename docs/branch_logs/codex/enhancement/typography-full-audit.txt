Branch: codex/enhancement/typography-full-audit
Date: 2026-06-23

Why was the branch needed:
The Programs route header visually drifted from Templates and Data Visualization, and app text sizing was spread across route CSS without a central, documented scale. The user requested a full typography audit so every visible text element is associated with a standard size, with any new sizes documented before use.

Outcomes of code changes:
PowerJack now defines the compact typography scale in shared tokens and documentation: header-1, header-2, sub-header, and info. App CSS was refactored to use those tokens, default browser text sizing is routed through the tokenized reset, snapshots were updated after visual inspection, and Playwright now audits rendered visible text sizes against the approved scale.

Implementation decisions that were made:
No new text size was added because the existing four roles covered route titles, section headings, body/action text, helper text, metrics, controls, and badges. The UX standards check was expanded from a reminder into an enforcement gate for raw CSS font sizes, inline font sizing, SVG text, canvas text APIs, missing token defaults, and unsupported typography exceptions. The only non-token exception remains `font-size: 0` for non-visible duplicate mobile badge text while preserving the icon affordance.
