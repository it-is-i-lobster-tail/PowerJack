Branch: codex/enhancement/rest-timer-top-nav-pill
Date: 2026-06-23

Why was the branch needed:
The rest timer initially appeared as a large workout-page pill and the off-workout resume banner included extra day context. The requested follow-up was to keep timer and resume controls in the upper navigation row with the PowerJack logo and menu, reduce horizontal footprint, shorten resume copy, remove day text from the off-workout timer, and change the expired next-set badge from Next to Go.

Outcomes of code changes:
The app shell now owns compact top-nav pill variants for active timers, off-workout resume timers, and idle resume. The active workout page no longer renders a separate timer pill, expired set rows display Go while preserving aria-current, and E2E coverage plus mobile snapshots were updated for the new layout. Browser QA also exposed and verified a fix for a web SQLite rest-timer persistence collision.

Implementation decisions that were made:
The branch uses the existing app shell top-bar center slot instead of introducing a new global overlay. Timer copy keeps the existing target-label helpers and stable data-agent selectors, while CSS uses fit-content sizing plus mobile max-width guards to prevent overlap with the logo and hamburger menu. Rest-timer persistence is serialized and retried only for transaction-busy web SQLite errors so countdown ticks remain in memory and persistence still happens only on meaningful state transitions.
