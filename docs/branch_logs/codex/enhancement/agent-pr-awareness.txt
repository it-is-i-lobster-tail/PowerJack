Branch: codex/enhancement/agent-pr-awareness
Date: 2026-06-23

Why was the branch needed:
The agent guide needed an explicit reminder for agents to check recently closed GitHub pull requests before starting substantial work. That scan helps future agents account for freshly merged changes that may affect the implementation, tests, or handoff.

Outcomes of code changes:
AGENTS.md now instructs agents to run a recent closed PR scan with gh and inspect relevant PR details or diffs. The branch also records the required branch change log and detailed branch log for final-review handoff.

Implementation decisions that were made:
The new guidance was placed under Agent And Test Readiness because it affects agent preparation and quality checks rather than application architecture or UI behavior. The instruction uses concise gh commands that match the requested workflow and keeps the existing guide style.
